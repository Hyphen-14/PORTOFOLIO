# Yasin Taryaqil Aghyar - Cyberpunk Portfolio 💻✨

Welcome to the source code of my interactive personal portfolio! This project is designed with a **Cyberpunk / Retro RPG** aesthetic, blending my passion for Cyber Security, Software Development, and creative frontend design.

## 🚀 Features

- **Interactive Start Screen:** An immersive "Unlock Profile" sequence featuring a digital padlock decryption animation and retro sound effects.
- **Cyberpunk Aesthetic:** Custom UI styling featuring neon glowing borders, scanlines, CRT screen effects, and a custom Indonesian Cyberpunk city background.
- **Dynamic Track Record:** A custom-built split timeline for the "Experience" section featuring fibrous energy beams and pulsing radiation nodes.
- **Achievements Board:** A beautifully rendered digital pin-board showcasing certifications and achievements.
- **RPG Elements:** Custom typing-text effects, 8-bit sound effects, and RPG dialog-style window frames.
- **Responsive Design:** Fully fluid layout that adapts perfectly from desktop monitors down to mobile devices.

## 🛠️ Tech Stack

- **Frontend:** Vanilla JavaScript, HTML5, CSS3
- **Build Tool:** [Vite](https://vitejs.dev/) for fast and optimized bundling
- **Design:** Custom CSS Grid/Flexbox layouts with advanced pseudo-element trickery (`::before`, `::after`) for glowing circuit traces.

## 📦 Local Development

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Hyphen-14/PORTOFOLIO---Yasin-Taryaqil-Aghyar.git
   ```
2. **Navigate into the project directory:**
   ```bash
   cd PORTOFOLIO---Yasin-Taryaqil-Aghyar
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Start the development server:**
   ```bash
   npm run dev
   ```
5. **Open your browser:** The terminal will output a local URL (usually `http://localhost:5173`).
